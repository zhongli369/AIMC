## 1. 实际生效的 TTS 通路 (Canonical Pipeline)

```
LLM 输出 / Fast Path 回复
  │
  ▼
legacy-bridge.cjs:handleChat()
  │  ├─ safeBotChat(bot, text)          ← Minecraft 聊天 (always)
  │  └─ if ttsEnabled: speakTTS(text)   ← TTS 语音 (optional, non-blocking)
  │
  ▼
legacy-bridge.cjs:speakTTS()  (line 643)
  │  ├─ cleanTtsText(text)              ← 清理 JSON 碎片 / MC 格式符 / 截断 120 chars
  │  ├─ {doubao}: doubaoTTS(text, opts) ← electron/tts-doubao.cjs → Promise<Buffer>
  │  └─ {edge}:   voiceTTS.speak(text)  ← dist/voice/tts-edge.js → streaming MP3
  │
  ▼
fs.writeFileSync(tmpFile, audioBuffer)    ← 写入 os.tmpdir()/aimc-tts-{ts}.mp3
  │
  ▼
playAudioWindows(tmpFile)                 ← PowerShell spawn → WPF MediaPlayer
```

### speakTTS 调用点 (5 处)

| 位置 | 触发条件 |
|------|---------|
| line 1072 | Fast path "过来" → `"来了，${targetName}！"` |
| line 1077 | Move error → `"抱歉${targetName}，我动不了。"` |
| line 1021 | Ping 无玩家 → `"我看不到任何玩家。"` |
| line 1047 | Pathfinder 未就绪 → `"抱歉...寻路系统还没准备好。"` |
| line 1141 | LLM 正常回复 → `normalized.speech.text` |

### 降级策略

- `speakTTS()` 所有调用均包裹 `.catch(() => {})` — TTS 失败不影响 bot.chat
- `initTTS()` 缺 key 时设 `ttsEnabled = false` — speakTTS 立即 return
- replace 策略: `ttsSpeaking` flag — 新话语覆盖旧话语

## 4. Doubao TTS API 正确性分析

### 当前实现 vs Volcengine 文档

| 字段 | 当前实现 | Volcengine TTS v1 要求 | 一致性 |
|------|---------|----------------------|--------|
| Endpoint | `https://openspeech.bytedance.com/api/v1/tts` | 文档正确 | ✓ |
| Method | POST | POST | ✓ |
| `app.appid` | String(appId) | 必需 | ✓ |
| `app.cluster` | String(cluster) | 必需 | ✓ |
| `app.token` | (已移除) | 可选 | ✓ |
| `audio.voice_type` | String(voice) | 必需 | ✓ |
| `audio.encoding` | "mp3" 或 "wav" | "mp3"/"wav" | ✓ |
| `request.reqid` | aimc-{ts}-{random} | 必需 | ✓ |
| `request.text` | 截断 ≤900 bytes | ≤1024 bytes | ✓ |
| `request.operation` | "query" | "query" | ✓ |
| Response code=3000 | 检查 | 成功标识 | ✓ |
| Response data | Base64 decode | Base64 encoded audio | ✓ |

### Auth 尝试历史

| 尝试 | Auth 方式 | 错误 |
|------|----------|------|
| 1 | `Bearer;{key}` (无 servername) | TLS socket disconnect |
| 2 | `Bearer {key}` (空格 + servername) | code=3001 "invalid auth token" |
| 3 | `Bearer;{key}` (分号 + servername) | code=3001 "grant not found in SaaS" |
| 4 | `X-Api-App-Key` + `X-Api-Access-Key` | code=3001 "missing Authorization header" |

### 根因结论

`DOUBAO_TTS_API_KEY` (UUID, redacted) **不是有效的 TTS Bearer token**。Volcengine TTS v1 API 需要:
1. 通过 Volcengine IAM 用 Access Key + Secret Key 换取临时 Bearer token
2. 在 `app.token` 和 `Authorization: Bearer;{token}` 中均使用该 token

当前的 UUID key 可能是:
- ARK API key (对 TTS API 无效)
- 或者是其他服务的 token

### 下一步验证

1. 在火山引擎控制台获取 TTS 服务的 "Access Key" 和 "Secret Key"
2. 用 Access Key/Secret Key 调用 IAM API 获取临时 token
3. 实现 token 交换逻辑 (或在外部生成 token 后通过 env var 传入)

| **二者不通用** | — | — | — |
